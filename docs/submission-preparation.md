# Trace: submission preparation

Working project title: **Trace — make every sample count**.

## Demonstrable problem
A coordinator with limited sampling capacity needs to choose which observation could actually change the working explanation. A polluted-looking location is not automatically the most informative place to test. Access, cost, data comparability and uncertain readings constrain the next move.

## Demonstrable product
A fictional short inflow network with three branches and a reference. The user sees possible explanations, gets an inspectable next comparison, records an interval, revises evidence, and exports a complete case. The system can stop with insufficient evidence or a model mismatch. A surviving explanation inferred by exclusion gets a direct cross-check if it is accessible and affordable.

## Distinctive approach
The product keeps reasoning and uncertainty visible. Instead of declaring a polluter from a map, it recommends a question that can separate candidate explanations. A correction reopens the conclusion while preserving the original observation. Accessibility and cost are first-class constraints. The numerical reasoning is deterministic and inspectable; no LLM invents chemistry or confidence scores.
