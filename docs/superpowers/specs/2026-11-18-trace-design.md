# Trace — investigation workspace

Build authorized by Arham on 18 November 2026. Fresh implementation, no existing LakeAlive code reused. Local delivery only: no contest submission, public deployment, or automatic external messages.

## Product
Help a monitoring coordinator choose the next accessible sample that can distinguish modeled upstream explanations under a fixed budget. Run an authentic fictional investigation: review evidence, compare choices, collect a simulated or entered reading, revise assumptions, and export a reproducible case. Every screen labels the fictional network and synthetic measurements. The prototype does not infer drinking-water safety or identify a polluter.

## Model and boundaries
Eight hypotheses represent all subsets of three potentially elevated branches (including no branch). Binary upstream connectivity plus explicitly synthetic concentration bands define expected observations. This is a demonstrator, not a transport/chemistry model. Interval intersection retains compatible hypotheses; no percentages or calibrated probabilities. Rank actions by the smallest worst-case compatible set across possible interval measurements (instrument half-width), then cost, then stable ID. Cost and access are scenario inputs, not local prices. Unknown/blocked sites are excluded. Out-of-range evidence, broad readings, unsupported methods, and insufficient budget must produce honest uncertainty. Hidden simulator outcomes are not passed to the planner.

Historical reference and outlet observations start each case; new samples cost credits. One current revision per sample enters inference; old revisions remain in the timeline. Corrections trigger complete recalculation. Condition changes suspend interpretation until acknowledged under a reset/clear evidence workflow, not silently recombine incompatible conditions. Data live locally and export/import through versioned validated JSON. Export report includes all evidence, assumptions, limitations, costs, and history; no evidentiary certification.

## Interface
Quiet editorial field atlas: cream paper, pine ink, teal water, orange route markers. A large custom SVG schematic, clear next-action card, linked evidence notebook, and model table. Responsive with keyboard controls and reduced-motion support. No stock AI chat, decorative metric grid, paid API, sign-up, or fake real-world results.

## Acceptance
Five scenarios (one source, multiple, restricted access, broad/ambiguous, contradictory). Functional site selection, access and budget controls, reading entry, edits, explicit review status, persistent state, reset, export report, import backup, method/evidence table. Unit and integration tests prove engine invariants, error boundaries, no duplicate counting, and safe imports. Deterministic evaluator reports synthetic performance and failure modes against fixed and random baselines. No claims of superiority without measurements. Build a fully portable offline HTML plus source archive.
